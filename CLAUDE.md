## This project

The imported conventions above are `software-factory`'s. Sections
"What this repo is" and "Issue tracking" describe that repo, not this
one — for this project:

- Issue tracking: two labels only, `epic` and `task` (see the
  `roadmap` skill). No piece labels.
- Design cycle: use the `plan-feature` skill. Specs go to `docs/specs/`.

Everything else — including "Starting a new project idea" (the
`discovery`/`prioritize-features` workflow) and "Git workflow" onward
— applies here as written; the templates it references
(`templates/discovery/`) live in this repo.
